# Curated Chat GIF Library

This directory is the staging area for the NCO Logger curated GIF library.

- `files/` contains locally hosted GIF assets after review.
- `metadata/manifest.json` records provenance, license, attribution, source URL, category, keywords, content rating, and review status for every asset.
- Only individually verified public-domain or appropriately open-licensed files should be admitted.
- Do not bulk-copy arbitrary Google Images or hotlink remote GIFs.
- Target library size: 500 reviewed GIFs, PG-13 maximum (G/PG preferred).

Licensing review is required per asset before it is marked approved.
